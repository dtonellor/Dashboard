# InsightCommerce Dashboard

Dashboard profissional para visualização de métricas de e-commerce, desenvolvido como projeto de portfólio.

## Funcionalidades

- **KPI Cards**: Receita Total, Pedidos, Ticket Médio, Taxa de Conversão
- **Gráficos Interativos**: Evolução de Vendas, Canais de Venda, Top Produtos, Clientes, Regiões
- **Tema Claro/Escuro**: Toggle com persistência via localStorage
- **Sidebar Colapsável**: Menu de navegação responsivo
- **Tabela de Pedidos**: Últimos pedidos com status
- **Design Responsivo**: Adaptável para desktop, tablet e mobile

## Tecnologias Utilizadas

- HTML5
- CSS3 (CSS Variables, Flexbox, Grid)
- JavaScript Vanilla
- Chart.js 4.4.0
- Google Fonts (Inter)

## Estrutura do Projeto

```
Dashboard/
├── index.html          # Página principal
├── css/
│   └── styles.css      # Estilos com tema claro/escuro
├── js/
│   ├── app.js          # Lógica principal da aplicação
│   ├── charts.js       # Configuração dos gráficos
│   └── data.js         # Dados fictícios de e-commerce
├── assets/
│   └── icons/          # Ícones
└── README.md           # Documentação
```

## Como Executar

1. Abra o arquivo `index.html` em um navegador moderno
2. Ou use um servidor local (ex: Live Server no VS Code)
